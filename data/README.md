# Hyperuniform datasets

This subfolder contains point samples with high quality spectrum. The folder itself contains only small datasets, 
for bigger datasets they can be downloaded separately from github large file storage (TODO).

- The 200k_2D_FIRE_princeton dataset contain is submitted to following licence, and can also downloaded directly from princeton datacommons under MIT licence
Morse, Peter K., Kim, Jaeuk, Steinhardt, Paul, & Torquato, Salvatore. (2023). Data for "Generating large disordered stealthy hyperuniform systems with ultra-high accuracy to determine their physical properties" [Data set]. Version 1. Princeton University. https://doi.org/10.34770/e49n-r807
